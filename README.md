# NB Contabilidade

Site institucional estático em HTML, CSS e JavaScript.

## Arquivos
- index.html: página e estilos do site
- nb-logo-oficial.png e nb-logo.png: logos
- nicoly-bueno-costa.jpeg: foto da responsável técnica
- escritorio-nb-tratado.png: foto do escritório
- robots.txt, sitemap.xml e llms.txt: arquivos de descoberta

## Publicação
Publique a raiz deste repositório em uma hospedagem estática. Para GitHub Pages, selecione a branch main e a pasta raiz nas configurações de Pages.

## Estado da versão exportada
Esta cópia preserva o conteúdo da versão 7 do Sites. O WhatsApp e o formulário de contato ainda estão em modo demonstrativo no site original. O formulário não envia mensagens. As URLs canonical, sitemap e robots apontam para o endereço atual do Sites e devem ser atualizadas quando for definido um novo domínio definitivo.

As fotografias e logos estão incluídas localmente. As fontes utilizam o Google Fonts.
